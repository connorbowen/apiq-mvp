Analysis

If all the logos look the same, it means Clearbit is returning the same generic Google logo for all Google services. This is a common issue with Clearbit's logo service.

Potential Solutions:

  • Use different domains: Try alternative domains like .app versions
  • Custom logos: Implement custom SVG logos for Google services
  • Different service: Use a different logo service like LogoAPI or Favicon.io
  • Manual logos: Manually set specific logos for each service
